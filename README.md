# Horizon Race

A dependency-free pseudo-3D kart racer built with vanilla JavaScript and Canvas 2D. Open `index.html` and race—no build step or external assets are required.

## Features

- 8 themed tracks, 12 racers, drift turbos, seven items, obstacles, and rubber-band AI.
- Procedural graphics and WebAudio sound effects; no image, audio, font, or CDN dependencies.
- Keyboard and gamepad support, rear view, pause, responsive HUD, and local best laps.
- Settings for 11 languages, render resolution, frame-rate cap, and nine remappable keyboard actions.

## Start

Open `index.html`, or run `python -m http.server 8080` and visit `http://localhost:8080`.

Use the arrow keys to navigate menus and `Enter` to confirm. Default driving controls are WASD/arrows, `Shift` to drift, `E` to use an item, `Q` for rear view, `P` to pause, and `R` to restart. Controls can be changed in Settings.
