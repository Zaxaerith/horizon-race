# Horizon Race

[简体中文](README.zh.md) | [English](README.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português](README.pt.md) | [Italiano](README.it.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Latina](README.la.md) | [Ελληνικά](README.el.md)

바닐라 JavaScript와 Canvas 2D로 만든 의존성 없는 유사 3D 카트 레이싱 게임입니다. 빌드 과정이나 외부 리소스 없이 `index.html`을 열면 바로 플레이할 수 있습니다.

## 주요 기능

- 8개 트랙, 12명 레이서, 드리프트 터보, 7종 아이템, 장애물과 적응형 AI.
- 이미지, 오디오, 글꼴, CDN이 필요 없는 절차적 그래픽과 WebAudio 사운드.
- 키보드와 게임패드, 후방 시점, 일시정지, 반응형 HUD, 로컬 최고 기록.
- 11개 언어, 렌더링 해상도, FPS 제한, 9개 키 설정을 지원하는 설정 화면.

## 실행

`index.html`을 열거나 `python -m http.server 8080`을 실행한 뒤 `http://localhost:8080`에 접속하세요.

메뉴는 방향키, 확인은 `Enter`입니다. 기본 조작은 WASD/방향키, 드리프트 `Shift`, 아이템 `E`, 후방 보기 `Q`, 일시정지 `P`, 재시작 `R`입니다.
