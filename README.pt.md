# Horizon Race

Um jogo de corrida de karts pseudo-3D sem dependências, criado com JavaScript puro e Canvas 2D. Abra `index.html`; não é necessário compilar nem baixar recursos externos.

## Recursos

- 8 pistas, 12 pilotos, turbo de drift, sete itens, obstáculos e IA adaptativa.
- Gráficos procedurais e áudio WebAudio sem imagens, sons, fontes ou CDN externos.
- Teclado e controle, visão traseira, pausa, HUD responsivo e melhores voltas locais.
- Configurações para 11 idiomas, resolução, limite de FPS e nove ações de teclado remapeáveis.

## Início

Abra `index.html`, ou execute `python -m http.server 8080` e visite `http://localhost:8080`.

Use as setas nos menus e `Enter` para confirmar. Padrão: WASD/setas, `Shift` para drift, `E` para item, `Q` para olhar para trás, `P` para pausar e `R` para reiniciar.
