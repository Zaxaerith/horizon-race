# Horizon Race

Un juego de carreras de karts pseudo-3D sin dependencias, creado con JavaScript nativo y Canvas 2D. Abre `index.html`; no necesita compilación ni recursos externos.

## Características

- 8 pistas, 12 pilotos, turbos de derrape, siete objetos, obstáculos e IA adaptativa.
- Gráficos procedurales y sonido WebAudio sin imágenes, audio, fuentes ni CDN externos.
- Teclado y mando, vista trasera, pausa, HUD adaptable y mejores vueltas locales.
- Ajustes para 11 idiomas, resolución, límite de FPS y nueve acciones de teclado configurables.

## Inicio

Abre `index.html`, o ejecuta `python -m http.server 8080` y visita `http://localhost:8080`.

Usa las flechas para los menús y `Enter` para confirmar. Controles predeterminados: WASD/flechas, `Shift` para derrapar, `E` para objetos, `Q` para mirar atrás, `P` para pausa y `R` para reiniciar.
