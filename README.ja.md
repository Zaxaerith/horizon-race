# Horizon Race

[简体中文](README.zh.md) | [English](README.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português](README.pt.md) | [Italiano](README.it.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Latina](README.la.md) | [Ελληνικά](README.el.md)

バニラ JavaScript と Canvas 2D で作られた、依存関係のない疑似3Dカートレースゲームです。ビルドや外部素材は不要で、`index.html` を開くだけで遊べます。

## 特徴

- 8コース、12人のレーサー、ドリフトターボ、7種類のアイテム、障害物、適応型AI。
- 画像・音声・フォント・CDNに依存しないプロシージャル描画とWebAudioサウンド。
- キーボードとゲームパッド、後方視点、ポーズ、レスポンシブHUD、ローカル記録。
- 11言語、描画解像度、FPS上限、9種類のキー割り当てを変更できる設定画面。

## 起動方法

`index.html` を開くか、`python -m http.server 8080` を実行して `http://localhost:8080` にアクセスしてください。

メニューは矢印キー、決定は `Enter`。初期設定はWASD／矢印、ドリフトは `Shift`、アイテムは `E`、後方視点は `Q`、ポーズは `P`、再スタートは `R` です。
